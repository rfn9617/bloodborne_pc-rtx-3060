# RTX 3060 Laptop: замеры и изменения 2026-10-10

i7-11800H, RTX 3060 Laptop 6 GB, DLSS K Quality (сцена 1280×720 → 1920×1080), лимит 72 FPS.
Тяжёлая точка в канализации: ~1800–1900 draws за кадр. A/B в одном прогоне через
`BB_TOGGLE_AB` (фазы по 20 с), сравниваются только 5-секундные окна целиком внутри фазы.

## Итоги

| Изменение | Метрика | Вкл | Выкл |
|---|---|---|---|
| Хэш палитр костей на stage A (4e86f51) | время записи на draw, весь прогон N против B | −14% | — |
| EnsureResident, IndexRange 240 кадров, memo сэмплеров (f8c3d18) | stage B, мкс на пакет | 3,19 | 3,64 |
| Слова вместо `std::bitset` в RegDirty (aa62fb7) | PostDraw, было 15% GPU command thread | — | — |
| Меньше холостого ожидания (6e3c277) | CPU процесса, ядер | 4,03 | 4,48 |

Потолок процессора в тяжёлой точке: stage B занят ~55% при 72 FPS (утром ~90% при 89 FPS).
Видеокарта там: нагрузка ~78%, 1807 МГц, 87 из 130 Вт, 75 °C, частота ничем не ограничена.

## Профиль (BB_CPU_SAMPLE)

Поток записи draw: BindResources 33% (текстуры 19%, буферы 10%), вершинные буферы 14%,
IndexRange 9% (до f8c3d18), смена защиты страниц (VirtualProtect при загрузке изменённых
страниц) ~6%, DLSS на CPU ~3%. Функций с собственной долей выше 5% почти нет: стоимость
распределена по промахам кэша в структурах изображений и буферов.

## Видеокарта

- Депт-буфер каждый кадр переносится в arena (`SynchronizeMemoryFromImage`: игра читает его
  память как texel buffer), затем загружается как R32F; плюс RGBA8. ~0,4 мс на кадр, в основном
  простой на барьерах. Не меняли: выигрыш мал, риск для картинки.
- Copy shader HLE: ~78 dispatch за кадр, 0,45 мс; уже объединён ранее.
- DLSS (модель K): ~1,8 мс на кадр вместе с подготовкой.

## Не работает

`BB_TEXTURE_HELPER=1` с draw pipeline: вспомогательный поток читал user data без снимка
stage B (thread-local) и брал не те T#. Мусор на экране. Теперь помощник не используется на
stage B (8f38835).

## Вечер: видеокарта без лимита кадров (прогоны U и G)

Без лимита: тяжёлая точка ~86 FPS, обычные места 110–120, лёгкие до 235. Видеокарта загружена на
97%, 1807 МГц, 95–100 из 130 Вт, ~78 °C: упирается в собственную производительность, не в
питание и не в температуру. Барьеров ~220 на кадр, проходов рендера ~170; почти все барьеры
нужны (цель рендера → чтение шейдером 64/кадр, обратно 57/кадр).

Время видеокарты на кадр (BB_GPU_PROFILE, шаги RunScaled):

| Шаг | мс |
|---|---|
| Глубина для интерфейса, входы | 0,07 |
| Векторы движения | 0,07 |
| DLSS, модель K | 1,34 |
| DLSS, модель E | 0,58 |
| Резкость и вывод: копия RGBA32F + RCAS + blit (было) | 0,34 |
| Резкость и вывод одним проходом (3d8e2b5, бит 64) | 0,14 |

Без эффекта: пропуск барьеров между двумя чтениями (бит 65; в игре такого случая нет) и лишний
кадр вперёд (бит 66; простой видеокарты между отправками 0,13 мс/кадр в обоих случаях).

## Загрузки (прогон L)

Чтение файлов занимает 5–20% экрана загрузки, потоки распаковки игры заняты меньше чем
наполовину, главный поток почти всё время ждёт. Короткая загрузка (Сон Охотника, 210 МБ) три
раза подряд длилась ровно 125 кадров при 72 FPS (1,73 с); без лимита кадров загрузки того же
объёма шли примерно вдвое быстрее. Проверка: BB_FAST_LOADING (6612f32).
