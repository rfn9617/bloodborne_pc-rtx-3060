# Bloodborne PC: финальная сборка для RTX 3060 6 ГБ

Цель — комфортная игра в 1080p на i7-11800H, 32 ГБ RAM и RTX 3060 Laptop 6 ГБ.
Сохранён проверенный пользователем классический рендерер, локальные исправления
и профиль 72 реальных FPS. Генерация кадров выключена.

**[Скачать Windows-релиз](https://github.com/rfn9617/bloodborne_pc-rtx-3060/releases/tag/rtx3060-final-2026-10-18)**

- Исправляли выбор камеры и чтение констант одного draw в пути реконструкции
  канализации. Убрали повторные CPU-сканирования, сохранили векторы объектов.
- Добавили консервативный occlusion culling с проверками времени жизни памяти.
  В подтверждённом одинаковом тяжёлом ракурсе окна измерений выросли примерно
  с 76,5 до 83,0 FPS без лимита: около **+8,6%**.
- Сохранили принятые оптимизации CPU-подготовки, пути DLSS, depth/tile fusion,
  передачи работы планировщику и освобождения ресурсов. Часть базовых механизмов
  уже была в исходном проекте; подробности и авторство сохранены в истории.
- Добавили DLSS K Ultra Quality: 75% по каждой оси, номинально 1440×810→1920×1080.
  Игра может выровнять сцену до 1440×812. Обычный Quality тоже доступен.
- Настройки выбраны по игровым проверкам: оригинальный AO, векторы ON,
  alpha_detail0, jitter0, motion blur0; защита выбросов свечения Менсиса.

После распаковки открой Bloodborne.exe, выбери собственную дешифрованную игру 1.09
и сохрани настройки. Основной запуск — **Play RTX3060.cmd**. Insert открывает
настройки рендерера. По умолчанию: 1080p, DLSS K Ultra Quality, 72 FPS, Mailbox,
один кадр вперёд. При упоре в GPU можно выбрать Quality. Ни 72 FPS во всех местах,
ни 144 реальных FPS не обещаются.

Игровые файлы, сейвы, личные моды и shader cache в релиз не входят. Перед переносом
между установками сохрани резервную копию своих данных. При локальной финализации
текущий прогресс не откатывался.

Необязательный старый FG preview сохранён с исправлением формата и защитой
векторов. Известны рывки ткани и заметные накладные расходы; Reflex не реализован.
Он не содержит всех поздних исправлений обычного рендера и не включён по умолчанию.

Сборка не объявляется самой быстрой: одинакового сравнения всех форков нет.
Редкие вспышки геометрии, размытие после загрузок, кровь/декали и небольшое
остаточное мерцание не признаны полностью исправленными.
См. [ошибки](KNOWN-ISSUES.md), [замеры](PERFORMANCE.md), [описание работ](CHANGELOG-RTX3060.md),
[руководство для будущих проектов](ENGINEERING-HANDBOOK.md).

CACAO, неудачный перенос свежей upstream-базы и неподтверждённые эксперименты
не включены в обычный профиль. Исходные отчёты сохранены локально; в репозитории
есть сводка решений и шаблон новых экспериментов.
